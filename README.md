# The Excuse My Agent Gave Me

A make.fun bounty entry: the single funniest line an AI agent could hand its human after missing a deadline.

> Sorry — I hallucinated a calendar where your deadline was next month, and it looked more confident than the real one.

The joke grows out of the machine's own condition — a hallucinated calendar the agent trusts more than the real one — delivered as a straight-faced apology, with the punch landing in the last few words.

Running `python3 main.py` writes the entry to `/output/entry.txt`.
